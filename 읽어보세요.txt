성피모 랜딩페이지 — 현재 상태와 남은 것
==========================================

주소 : https://pcpc.li
틀   : pc365.it.kr 과 HTML·CSS·JS 골격이 같습니다. 글·링크·이미지·파비콘만 성피모용입니다.


■ 도메인 — 반영 완료
----------------------
pcpc.li 로 전부 들어갔습니다.
  · index.html 30곳 (canonical, og:url, 구조화데이터 등)
  · robots.txt, sitemap.xml
  · CNAME 파일 생성 (깃허브 페이지에 올릴 때 쓰입니다)

주소를 또 바꿀 일이 생기면 이 폴더에서 PowerShell 로 아래 한 줄.
(끝에 / 를 붙이지 마세요)

  Get-ChildItem -Include *.html,*.xml,*.txt -Recurse |
    ForEach-Object { (Get-Content $_ -Raw -Encoding UTF8) -replace 'https://pcpc\.li','https://새주소' |
    Set-Content $_ -NoNewline -Encoding UTF8 }

CNAME 파일 내용도 같이 바꾸세요 (https:// 없이 주소만).


■ 올린 다음에 할 일
---------------------
1. 구글 서치콘솔 (search.google.com/search-console) 에 pcpc.li 등록
   → 받은 확인 코드를 index.html 의 "검색엔진 소유권 확인" 주석 안에 넣고 주석 해제
   → sitemap.xml 제출

2. 네이버 서치어드바이저 (searchadvisor.naver.com) 에도 같은 방식으로 등록
   robots.txt 에 네이버 봇(Yeti) 허용이 이미 들어가 있습니다.

3. 카톡·텔레그램에 링크를 한 번 붙여넣어 썸네일이 뜨는지 확인
   (og-image.jpg 1200x630 이 미리 들어가 있습니다)


■ 텔레그램
------------
https://t.me/pc365s 로 4곳이 연결되어 있습니다.
  · 히어로 버튼 2개 (가입 문의 / 인증 안내)
  · 404 페이지 버튼
  · 구조화데이터 sameAs
바꾸려면 index.html 에서 t.me/pc365s 를 찾아 바꾸세요.
